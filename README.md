# Sistema Kumo — Website

Site institucional da Kumo, empresa de soluções em tecnologia.

## Estrutura

Projeto estático, sem dependências de build. Pode ser publicado diretamente na Vercel.

- `index.html` — homepage
- `styles.css` — identidade visual e responsividade
- `script.js` — navegação, animações e área do cliente

## URLs dos produtos

As URLs dos produtos estão centralizadas em `script.js`:

- CRM: https://crm.sistemakumo.com.br
- Meu Caixa: https://caixa.sistemakumo.com.br

Quando os domínios finais estiverem definidos, altere apenas o objeto `PRODUCT_URLS`.
